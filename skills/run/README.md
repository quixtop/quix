# run — generic script-backed slash commands

Drop an executable script into this skill and `register` it. A matching
`/scriptName` slash command shows up on the Claude Code input bar. Invoking it
runs the script.

## File layout

```
~/.agents/skills/run/
  README.md                       human-facing reference (this file)
  SKILL.md                        skill manifest + dispatch body
  bin/
    runctl                        Python CLI, subcommand dispatch
  scripts/
    rmApp.sh                      registered scripts (symlinked here on register)
    foo.py
    ...
    .trash/
      2026-04-16_143022/
        oldScript.sh              soft-trashed on unregister

~/.claude/skills/run               symlink -> ~/.agents/skills/run
~/.claude/commands/
  rmApp.md                         generated by runctl register
  foo.md
```

`~/.agents/` holds only `skills/` — there is no `~/.agents/commands/`. The
command files in `~/.claude/commands/` are written directly by `runctl
register` and are specific to this skill; other skills are independent.

## Conventions

- **Registration is the only path** that writes a command file into
  `~/.claude/commands/`. No auto-sync, no session-start hook, no manifest.
  Dropping a script into `scripts/` without `register` does nothing.
- **Symlink semantics** on register — the source file is symlinked into
  `scripts/`, origin untouched. Edits to the origin are live in the command
  with no re-register; deleting the origin leaves a dangling symlink.
- **Soft-trash** on unregister — the script moves to
  `scripts/.trash/<ISO-timestamp>/` and the command file is deleted. Recover
  by `mv`-ing the script back out of trash.
- **Name** defaults to the source basename (`foo` → `/foo`; a trailing `-x` on the
  source basename is stripped). The command and its backing script share this plain
  name. Override with `--as NAME`, used verbatim.
- **Description** comes from the first `#` comment line after the shebang.
  Override with `--desc "..."`. Fallback: `"Run script <name>"`.
- **Arguments** flow as `$ARGUMENTS` → positional `$1 $2 ...` inside the
  script.
- **Any shebang'd executable** is accepted (`.sh`, `.py`, `.js`, etc.).
- **Names `run` and `help` are reserved** to avoid clashing with the
  aggregator's own subcommands.

## CLI reference

Run `bin/runctl help` for the authoritative reference.

| Subcommand | Purpose |
|------------|---------|
| `register <path> [--as NAME] [--desc "..."] [--force]` | Symlink script in, write command file |
| `unregister <name>` | Soft-trash script + remove command file |
| `rename <old> <new>` | Rename script file and command file together |
| `list` | Show registered scripts; flag dangling/orphan pairs |
| `exec <name> [args...]` | Run a registered script (used by the skill) |
| `help` | Print usage |

## Invocation from Claude Code

- `/run register ~/scripts/foo.sh` — register
- `/run list` — inspect
- `/foo` — execute the registered script (once registered)
- `/run foo` — same, via the aggregator
- `/run unregister foo` — remove

## Activation

This skill is activated by creating a symlink at `~/.claude/skills/run`
pointing at `~/.agents/skills/run`. Manage through `skillctl` or by hand.

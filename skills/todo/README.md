# todo

A personal todo list in a markdown file you choose. Needs: Python 3.

## Install

```bash
curl -fsSL https://quixtop.com/i | sh -s -- todo
```

## Requires

- [Python 3](https://www.python.org)

## Usage

Invoke it as `/todo` in Claude Code.

Personal todo list manager backed by a configurable file (default ~/md/todo.md, folders as ## headings). Use when the user runs /todo to view, add, remove, complete/un-complete items, clear done items, or set the file path. NOT for project task tracking (use proj-tasks).

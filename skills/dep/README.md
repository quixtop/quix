# dep

Ship recent changes wherever they run — gate, review, deploy, prove, log — in one command.

## Install

```bash
curl -fsSL https://quixtop.com/i | sh -s -- dep
```

## Usage

Invoke it as `/dep` in Claude Code.

Ship recent dev changes wherever they run — restart a service, build a client bundle, publish to a host — through a change-gated pipeline ending in a shipped table, a smoke-check widget and a deplog entry. Triggers on the bareword `dep` (also `dep <target>`, `dep server`/`srv`/`s`, `dep ext`/`extn`/`e`, `dep both`/`all`, `dep <target> force`) and on `deploy`/`go live`.

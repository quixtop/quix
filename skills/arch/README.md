# arch

Bring a project's architecture pictures up to date in one step — the system picture, the STE100 sheet and the hub page that shows them.

## Install

```bash
curl -fsSL https://quixtop.com/i | sh -s -- arch
```

## Usage

Invoke it as `/arch` in Claude Code.

Bring a project's architecture pictures up to date in one step — archify's system picture (docs/arch/archify.html), the STE100 sheet (docs/arch/ste100.html, via /ste100) and the docs/arch.html hub that shows them as tabs — running only what the change needs. Use after an arch change, or on /arch, 'update the arch diagram', 'refresh arch.html'. NOT for writing arch prose (/spec) or STE rewrites alone (/ste100).

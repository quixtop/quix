# prayer

Comply with the rules. Strictly, from here on.

1. Read **every** file in `~/.claude/rules/` and `~/.claude/CLAUDE.md`, in full
   — whatever is there now, including files and edits made since this session
   started.
2. Say in one line that they are re-read and binding strictly from this turn on.
3. Continue whatever the session was doing.

## Constraints

- Read the files themselves; never summarise them and never reprint them.
- Read every file, not a selection.
- This file names no rule and quotes no rule — rules change, and anything
  restated here would go stale.
- Forward only: no auditing, scoring, or reporting what was missed earlier.
- Strictly means strictly. If a gate applies, it fires.

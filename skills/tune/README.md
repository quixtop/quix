# tune

Make anything that already exists faster, cheaper or clearer, its purpose unchanged — every gain measured against a stated goal.

## Install

```bash
curl -fsSL https://quixtop.com/i | sh -s -- tune
```

## Usage

Invoke it as `/tune` in Claude Code.

The optimizer — makes anything that already exists faster, cheaper or clearer with its purpose unchanged (code, scripts, SQL, tests, docs, rules, skills, prompts, designs, Claude Code setup (hooks, MCP, settings, context load), configs, CI, data, assets); every gain measured against a stated goal. Triggers on /tune, 'optimize this', 'make X faster / smaller / leaner / clearer', 'cut the tokens', 'slim this down'. NOT a redesign, a bug hunt (/rev), doc–code sync (/spec), a cleanup of a fresh diff (/simplify) or a repo audit (/code-audit).

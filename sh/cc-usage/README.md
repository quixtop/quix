# cc-usage

Your Claude usage gauge — the 5-hour and weekly limits.

## Install

```bash
mkdir -p ~/.local/bin && curl -fsSL https://raw.githubusercontent.com/quixtop/quix/main/sh/cc-usage/cc-usage -o ~/.local/bin/cc-usage && chmod +x ~/.local/bin/cc-usage
```

## Usage

Run `cc-usage -h`.

# dedup

Reclaim space by APFS-cloning duplicate files — deletes nothing.

## Install

```bash
mkdir -p ~/.local/bin && curl -fsSL https://raw.githubusercontent.com/quixtop/quix/main/sh/dedup/dedup -o ~/.local/bin/dedup && chmod +x ~/.local/bin/dedup
```

## Usage

Run `dedup -h`.

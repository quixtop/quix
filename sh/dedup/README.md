# dedup

Reclaim space by APFS-cloning duplicate files — deletes nothing. Needs: Python 3.

## Install

```bash
curl -fsSL https://quixtop.com/i | sh -s -- dedup
```

## Requires

- [Python 3](https://www.python.org)

## Usage

Run `dedup -h`.

# serve

A local HTTP server that shuts itself down when idle.

## Install

```bash
mkdir -p ~/.local/bin && curl -fsSL https://raw.githubusercontent.com/quixtop/quix/main/sh/serve/serve -o ~/.local/bin/serve && chmod +x ~/.local/bin/serve
```

## Usage

Run `serve -h`.

# serve

A local HTTP server that shuts itself down when idle. Needs: Python 3.

## Install

```bash
curl -fsSL https://quixtop.com/i | sh -s -- serve
```

## Requires

- [Python 3](https://www.python.org)

## Usage

Run `serve -h`.

# proj-env.sh

Shared shell helpers the other scripts source — status lines, colours, project paths.

## Install

```bash
mkdir -p ~/.local/bin && curl -fsSL https://raw.githubusercontent.com/quixtop/quix/main/sh/proj-env.sh/proj-env.sh -o ~/.local/bin/proj-env.sh && chmod +x ~/.local/bin/proj-env.sh
```

## Usage

```text
proj-env.sh - Common environment helper script used by a few skills
```

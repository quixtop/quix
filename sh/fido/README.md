# fido

Compare two directories — line counts and diffs, side by side.

## Install

```bash
mkdir -p ~/.local/bin && curl -fsSL https://raw.githubusercontent.com/quixtop/quix/main/sh/fido/fido -o ~/.local/bin/fido && chmod +x ~/.local/bin/fido
```

## Usage

Run `fido -h`.

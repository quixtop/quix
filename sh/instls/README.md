# instls

Inventory installed apps, brew, npm and pip as Markdown and HTML. Needs: Python 3, Homebrew.

## Install

```bash
curl -fsSL https://quixtop.com/i | sh -s -- instls
```

## Requires

- [Python 3](https://www.python.org)
- [Homebrew](https://brew.sh)

## Usage

Run `instls -h`.
